## 📂 Cấu trúc thư mục
Dự án được tổ chức theo cấu trúc sau để đảm bảo tính gọn gàng và dễ theo dõi:
* `data/`: Chứa các file dữ liệu. *(Lưu ý: Không push file data thô có dung lượng lớn lên GitHub)*.
* `notebooks/`: Chứa các file Jupyter Notebook (`.ipynb`) dùng để EDA và thử nghiệm mô hình.
* `src/`: Chứa mã nguồn Python chính thức (`.py`) cho pipeline.
* `report/`: Chứa mã nguồn báo cáo LaTeX và file PDF hoàn chỉnh.
